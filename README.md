# e-HCMS ? Electronic Honorary Consul Management System

**Ministry of Foreign and Diaspora Affairs (MFDA) ? Republic of Kenya**

e-HCMS is a centralized, role-based governance platform for managing Kenya's Honorary Consuls worldwide, featuring diplomatic mission registration, contract issuance, dual-channel Email & SMS Multi-Factor Authentication (MFA), activity logs, quarterly reports, Head of Mission endorsements, automated contract expiry alerts, and immutable audit logging.

> **Full Technical & Operations Manual:** See [`e-HCMS_System_Documentation.pdf`](./e-HCMS_System_Documentation.pdf) in the repository root for complete architecture, role matrices (Honorary Consul, Head of Mission, HQ Desk Officer, HQ Director, Super Admin), installation steps for Windows/Linux, environment variables, default test credentials, and API endpoints.
